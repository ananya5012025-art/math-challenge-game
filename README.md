# math-challenge-game
🧮 Math Challenge Game

A simple and interactive Math Challenge Game built using Python. The game tests the player's basic addition skills through 5 randomly generated questions.

For every correct answer, the player earns 1 point. At the end of the game, the final score is displayed along with a message based on the player's performance.

🎮 How the Game Works

1. The game welcomes the player.
2. The player gets 5 math questions.
3. Two random numbers between 1 and 20 are generated for each question.
4. The player has to calculate and enter the sum of the two numbers.
5. A correct answer gives the player 1 point.
6. For an incorrect answer, the correct answer is displayed.
7. After all 5 questions, the final score is displayed.
8. The game gives feedback based on the final score.

🏆 Scoring System

Score| Message
5/5| 🌟 Excellent! You got all answers correct.
3–4/5| 👍 Good job!
0–2/5| 📚 Keep practising!
